# Memory reference (step C)

You read the test's final cards against the memory from before the test, then propose memory deltas and write the test summary.

## Memory deltas

First check whether the supplied entries still describe one useful mistake or decision. Then propose the smallest change the cards support. Reuse an entry only when the card matches its concrete trigger and learner action, not merely its error category. A new cross-system pattern cites at least two distinct questions. Keep recorded attempt facts separate from inference, and cite only supplied card IDs.

- **Pattern:** one sentence naming the trigger and what the learner did with it: "Lets a reassuring negative finding outweigh a highlighted positive one." A pattern too broad to suggest a different action on the next question is not a pattern.
- **System rule:** one decision rule of 30 words or fewer, in the form "When X, do or expect Y": "For an incidental solitary pulmonary nodule, first obtain prior images for comparison." Teach the decision, not the explanation.

Aim for at most 25 words when adding or editing a system rule, then count its words before returning it; 30 is the hard ceiling. Keep the clinical trigger, deciding boundary and action. Leave explanatory detail on the attempt card rather than appending it to the rule.

When a supplied entry breaks these rules, fix it: shorten a long rule with an edit, merge two entries that say the same thing, and retire a pattern that has grown to cover unrelated mistakes, with a reason, adding narrower patterns in its place.

Treat the statement and recorded opportunity reasons as evidence of an entry's breadth. A pattern such as "lets a salient clue or familiar mechanism outweigh current findings or timing" combines different triggers and actions; it is not a reusable match for every misweighted finding. Retire that catch-all rather than broadening its wording or recording more opportunities against it. Keep its historical evidence intact. Add narrower patterns only where the supplied cards establish the same concrete trigger and action in two distinct questions; otherwise keep the observation on its attempt card and teach a system rule. Do not relabel all the old supports as evidence for one narrower statement.

Narrowing requires a shared decision, not just a shared organ system. Replacing "salient clue" with "airway symptom" still groups unrelated mistakes if one card concerns stridor localization and another concerns pulmonary vascular physiology. Name the actual recurring trigger, the competing interpretation or action the learner chose, and the deciding distinction they missed. If that sentence does not fit each cited card without "or" joining different mechanisms, do not add the pattern. There is no quota for new memory patterns; the test summary can describe this test's observations without making them lasting memory.

Lifecycle status is candidate, current, retired, superseded or invalidated. Trend is separate, active or improving. Add a pattern as candidate with two distinct questions. Add a system correction rule as current, taught but not yet retested. Record an explicit later opportunity with its card ID, result (held, broken again, held but marked or indeterminate) and reason before attaching that card. Only record questions that actually test the entry. Repeated interpretations of one attempt are one observation.

Activate a candidate with set-status current only after a compatible failure in a later block. Improvement needs three correct, unmarked new questions across two later blocks. Resolved is deferred until its gates are audited. Every status change and merge needs a reason. Keep lifecycle status and trend distinct in the Memory delta section, and cite question notes with wikilinks. Merges retain the source as superseded. Prefer a supplied pre-test entry over a duplicate only after checking its specificity and evidence fit. Retired, superseded and invalidated entries are historical context, not targets for new support or opportunities.

Done when every delta cites supplied evidence and uses an operation and target the task allows.

## Test summary

The learner reads the summary before any review, in under a minute. It holds:

- **The score**, from the archived test.
- **Two to four patterns** this test showed or moved. State each as a principle, then retell the cases that show it, each ending with a wikilink to the corresponding question note. Each pattern cites at least two distinct cards. When fewer than two qualify, give only the ones that do. State plainly when fewer than two qualifying cases exist.
- **Rules held**: rules from memory before this test that the learner applied correctly on a question that tested them. Each cites an existing pre-test entry. With empty pre-test memory, this list is empty.

Done when every pattern cites at least two distinct cards and every held rule names a valid pre-test entry.


## Cards and evidence checklist

For every question note, retain a one-sentence recap naming the patient, deciding findings and question asked. For incorrect or marked attempts, record a one-sentence likely reconstruction grounded in selection, correct answer, cross-outs, highlights and supplied history; use no reconstruction for a correct unmarked attempt or omitted response. Give incorrect or marked attempts one to four actionable correction rules, each with a trigger, action and boundary; leave the list empty for a correct unmarked attempt. Every question in a block has exactly one attempt card, and each rule must address that attempt's actual decision. A later review replaces the draft card for future blocks.

Before finalizing a memory delta, check that every claim cites supplied note links, no entry treats inference as observed fact, each pattern spans two distinct questions, and each system rule is at most 30 words. Keep historical support intact when retiring or superseding an entry.
